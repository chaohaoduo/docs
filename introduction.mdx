## 快速开始

<Steps>
  <Step title="创建 Google 账户">
    访问 [Google 账户注册页面](https://accounts.google.com/signup)，填写基本信息即可免费创建账户，同时解锁所有 Google 核心产品的访问权限。
  </Step>
  <Step title="选择适合您的产品">
    浏览[产品介绍](/getting-started/overview)页面，了解每款产品的核心功能与使用场景，找到最符合您需求的解决方案。
  </Step>
  <Step title="开启您的 API 之旅">
    前往 [Google Cloud Console](https://console.cloud.google.com) 创建项目、启用所需 API，并获取 API 密钥。参阅 [API 快速入门](/getting-started/quickstart) 在几分钟内完成首次调用。
  </Step>
  <Step title="深入探索文档">
    查看[核心功能](/features/ai-capabilities)与[使用指南](/guides/account-setup)，掌握进阶用法与最佳实践。
  </Step>
</Steps>
