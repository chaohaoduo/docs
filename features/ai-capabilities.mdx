## Cloud Vision API 示例

您可以通过 Cloud Vision API 快速实现图片内容理解，以下示例演示如何调用图像标注接口：

```bash
# 调用 Cloud Vision API 对图像进行多维度分析
curl -X POST \
  "https://vision.googleapis.com/v1/images:annotate?key=YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "requests": [
      {
        "image": {
          "source": {
            # 替换为您的公开图片 URL
            "imageUri": "https://example.com/sample-image.jpg"
          }
        },
        "features": [
          {
            # 标签检测：识别图片中的物体与场景
            "type": "LABEL_DETECTION",
            "maxResults": 10
          },
          {
            # 文字识别：提取图片中的文本内容
            "type": "TEXT_DETECTION"
          },
          {
            # 安全检测：检测不适宜内容
            "type": "SAFE_SEARCH_DETECTION"
          }
        ]
      }
    ]
  }'
```

<Note>
  请将 `YOUR_API_KEY` 替换为您在 Google Cloud Console 中创建的 API 密钥。建议对密钥设置 IP 限制或 API 限制以提高安全性。
</Note>

## Vertex AI 快速体验

<Steps>
  <Step title="打开 Cloud Console">
    访问 [Google Cloud Console](https://console.cloud.google.com)，使用您的 Google 账号登录，并选择或创建一个项目。
  </Step>
  <Step title="导航至 Vertex AI">
    在左侧导航菜单中，依次展开「人工智能」分类，点击 **Vertex AI**，进入 Vertex AI 控制台主页。
  </Step>
  <Step title="打开 Model Garden">
    在 Vertex AI 控制台中，点击左侧菜单的 **Model Garden（模型花园）**，浏览 Google 提供的全系列基础模型，包括 Gemini 系列。
  </Step>
  <Step title="使用提示词体验 Gemini">
    在 Model Garden 中找到 **Gemini** 模型卡片，点击「打开」进入 Vertex AI Studio。在文本输入框中输入您的提示词（例如："用中文写一份产品发布公告"），点击「提交」即可即时获得模型输出。
  </Step>
</Steps>

<Tip>
  想深入了解 Vertex AI 的完整功能，包括模型微调、批量预测与 MLOps 流水线，请访问官方文档：[https://cloud.google.com/vertex-ai](https://cloud.google.com/vertex-ai)
</Tip>
