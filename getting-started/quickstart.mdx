本指南将带您从零开始，完成以下四个关键步骤：创建 Google Cloud 项目、在控制台中启用所需 API、生成 API 密钥，以及通过实际请求验证一切配置均已就绪。完成后，您将拥有一个可用的 Google API 集成环境，为后续开发打下基础。

## 操作步骤

<Steps>
  <Step title="创建 Google 账户">
    如果您尚未拥有 Google 账户，请先前往 [accounts.google.com/signup](https://accounts.google.com/signup) 完成注册。已有账户的用户可直接跳过此步骤。

    注册时建议使用企业邮箱或专用开发账号，以便与个人账户区分管理。
  </Step>

  <Step title="访问 Google Cloud Console 并创建项目">
    打开 [Google Cloud Console](https://console.cloud.google.com)，使用您的 Google 账户登录。

    1. 点击页面顶部导航栏中的项目选择器下拉菜单。
    2. 在弹出窗口中点击右上角的「**新建项目**」按钮。
    3. 在「项目名称」字段中输入一个便于识别的名称（例如：`my-first-api-project`）。
    4. 根据需要选择关联的结算账户与组织，然后点击「**创建**」。

    项目创建完成后，Cloud Console 将自动切换至新项目的仪表盘。
  </Step>

  <Step title="启用 API">
    在 Cloud Console 左侧导航菜单中，依次点击「**API 和服务**」>「**库**」。

    1. 在搜索框中输入您想启用的 API 名称（本指南以 **Custom Search API** 为例）。
    2. 在搜索结果中点击对应的 API 卡片，进入 API 详情页。
    3. 点击「**启用**」按钮，等待几秒钟直至启用完成。

    启用成功后，页面将跳转至该 API 的管理界面，您可以在此查看使用配额与调用统计。
  </Step>

  <Step title="创建 API 密钥">
    在左侧菜单中点击「**API 和服务**」>「**凭据**」，进入凭据管理页面。

    1. 点击页面顶部的「**创建凭据**」按钮，在下拉菜单中选择「**API 密钥**」。
    2. 系统将自动生成一个 API 密钥并弹窗展示，请点击复制图标将密钥保存至安全位置。
    3. 点击「**关闭**」完成创建。

    请妥善保管您的 API 密钥，切勿将其提交至公开代码仓库或直接暴露在客户端代码中。
  </Step>

  <Step title="发起首次 API 请求">
    一切准备就绪！现在使用以下 `curl` 命令发起您的第一次 API 调用，将 `YOUR_API_KEY` 替换为上一步获取的密钥，将 `YOUR_SEARCH_ENGINE_ID` 替换为您的自定义搜索引擎 ID：

    ```bash
    curl "https://www.googleapis.com/customsearch/v1?key=YOUR_API_KEY&cx=YOUR_SEARCH_ENGINE_ID&q=Google"
    ```

    请求成功后，您将收到类似如下的 JSON 响应：

    ```json
    {
      "kind": "customsearch#search",
      "url": {
        "type": "application/json",
        "template": "https://www.googleapis.com/customsearch/v1?q={searchTerms}&..."
      },
      "queries": {
        "request": [
          {
            "title": "Google Custom Search - Google",
            "totalResults": "2900000000",
            "searchTerms": "Google",
            "count": 10,
            "startIndex": 1
          }
        ]
      },
      "items": [
        {
          "title": "Google",
          "link": "https://www.google.com",
          "snippet": "搜索全球信息，包括网页、图片、视频及更多内容..."
        }
      ]
    }
    ```

    收到包含 `items` 数组的响应即表示您的 API 调用已成功完成。
  </Step>
</Steps>

## 使用多种语言发起请求

除了 `curl`，您还可以在应用程序中通过以下方式集成 Google API：

<CodeGroup>

```python Python
import requests  # 需要先安装：pip install requests

# 替换为您的实际 API 密钥和搜索引擎 ID
API_KEY = "YOUR_API_KEY"
SEARCH_ENGINE_ID = "YOUR_SEARCH_ENGINE_ID"
查询词 = "Google"

# 构建请求 URL
url = "https://www.googleapis.com/customsearch/v1"
params = {
    "key": API_KEY,
    "cx": SEARCH_ENGINE_ID,
    "q": 查询词,
}

# 发起 GET 请求
response = requests.get(url, params=params)

# 检查响应状态
if response.status_code == 200:
    data = response.json()
    # 遍历并打印每条搜索结果的标题与链接
    for item in data.get("items", []):
        print(f"标题：{item['title']}")
        print(f"链接：{item['link']}")
        print("---")
else:
    print(f"请求失败，状态码：{response.status_code}")
    print(response.text)
```

```javascript JavaScript (Node.js)
// 替换为您的实际 API 密钥和搜索引擎 ID
const API_KEY = "YOUR_API_KEY";
const SEARCH_ENGINE_ID = "YOUR_SEARCH_ENGINE_ID";
const 查询词 = "Google";

// 构建请求 URL
const url = new URL("https://www.googleapis.com/customsearch/v1");
url.searchParams.set("key", API_KEY);
url.searchParams.set("cx", SEARCH_ENGINE_ID);
url.searchParams.set("q", 查询词);

// 使用 fetch 发起请求（Node.js 18+ 原生支持）
async function search() {
  try {
    const response = await fetch(url.toString());

    // 检查响应状态
    if (!response.ok) {
      throw new Error(`请求失败，状态码：${response.status}`);
    }

    const data = await response.json();

    // 遍历并打印每条搜索结果的标题与链接
    for (const item of data.items ?? []) {
      console.log(`标题：${item.title}`);
      console.log(`链接：${item.link}`);
      console.log("---");
    }
  } catch (error) {
    console.error("发生错误：", error.message);
  }
}

search();
```

</CodeGroup>

<Warning>
  **请务必在生产环境中限制 API 密钥的使用范围。** 未加限制的 API 密钥一旦泄露，可能导致配额被滥用并产生意外费用。建议您在 Cloud Console 的凭据设置中为密钥配置 HTTP 引用来源限制、IP 地址白名单或 API 使用范围约束。了解更多最佳实践，请参阅[安全指南](/features/security)。
</Warning>

</Tip>
