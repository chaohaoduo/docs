Google Maps Platform 是一套强大的地理位置服务 API 集合。本文档涵盖最常用的四个 API：**Maps JavaScript API**（在网页中嵌入可交互地图）、**Geocoding API**（地址与经纬度互转）、**Directions API**（路线规划）以及 **Places API**（地点搜索与详情查询）。所有 Maps Platform API 均通过 API 密钥进行认证，并统一通过 [Google Cloud Console](https://console.cloud.google.com/) 进行管理和计费。

<Note>
  在开始之前，请确保您已在 Google Cloud Console 中创建项目、启用所需的 Maps Platform API，并生成 API 密钥。建议为每个 API 单独限制密钥权限。
</Note>

## Maps JavaScript API

Maps JavaScript API 允许您在网页中嵌入功能完整的 Google 地图，支持标注、信息窗口、自定义样式、街景等丰富功能。

### 加载 API

通过在 HTML 页面中添加以下 `<script>` 标签来异步加载 Maps JavaScript API：

```html
<!-- 异步加载 Maps JavaScript API，替换 YOUR_API_KEY 为您的密钥 -->
<script
  async
  defer
  src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&callback=initMap&language=zh-CN"
></script>
```

<Tip>
  在 URL 中添加 `language=zh-CN` 参数，可将地图界面和地名显示切换为简体中文。
</Tip>

### 渲染地图示例

以下示例展示如何在网页中渲染一张以北京天安门广场为中心的地图：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>北京地图示例</title>
    <style>
      /* 设置地图容器高度，必须明确指定高度，否则地图不显示 */
      #map {
        height: 500px;
        width: 100%;
      }
    </style>
  </head>
  <body>
    <!-- 地图渲染容器 -->
    <div id="map"></div>

    <script>
      // 地图初始化回调函数，API 加载完成后自动调用
      function initMap() {
        // 定义地图中心点（北京天安门广场坐标）
        const beijing = { lat: 39.9042, lng: 116.4074 };

        // 创建地图实例
        const map = new google.maps.Map(document.getElementById("map"), {
          center: beijing,       // 地图中心点
          zoom: 13,              // 缩放级别（1=世界，20=建筑物级别）
          mapTypeId: "roadmap",  // 地图类型：roadmap（路线图）| satellite（卫星图）| hybrid | terrain
        });

        // 在中心点添加标记
        const marker = new google.maps.Marker({
          position: beijing,
          map: map,
          title: "天安门广场",  // 鼠标悬停时显示的文字
        });

        // 添加信息窗口
        const infoWindow = new google.maps.InfoWindow({
          content: "<h3>天安门广场</h3><p>北京市东城区</p>",
        });

        // 点击标记时打开信息窗口
        marker.addListener("click", () => {
          infoWindow.open(map, marker);
        });
      }
    </script>

    <!-- 异步加载 Maps JavaScript API -->
    <script
      async
      defer
      src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&callback=initMap&language=zh-CN"
    ></script>
  </body>
</html>
```

### 关键参数说明

| 参数 | 类型 | 说明 |
|------|------|------|
| `center` | `{lat, lng}` | 地图中心点的经纬度坐标对象 |
| `zoom` | `integer` | 缩放级别，范围 0（全球）到 22（建筑物），常用值 10–16 |
| `mapTypeId` | `string` | 地图类型：`roadmap`（默认）、`satellite`、`hybrid`、`terrain` |

## Geocoding API

Geocoding API 提供双向地理编码功能：**正向地理编码**（地址 → 经纬度）和**反向地理编码**（经纬度 → 地址）。

**Base URL：** `https://maps.googleapis.com/maps/api/geocode/json`

### 请求参数

<ParamField query="address" type="string" required>
  需要进行地理编码的地址字符串（正向地理编码）。例如：`北京市朝阳区建国路`。与 `latlng` 参数互斥——正向编码使用 `address`，反向编码使用 `latlng`。
</ParamField>

<ParamField query="key" type="string" required>
  您的 Google API 密钥。该密钥需在 Cloud Console 中启用 Geocoding API。
</ParamField>

<ParamField query="language" type="string">
  响应结果的语言代码。例如：`zh-CN`（简体中文）、`zh-TW`（繁体中文）、`en`（英语）。默认语言由请求地区自动决定。
</ParamField>

<ParamField query="region" type="string">
  区域偏置参数，使用 [ccTLD](https://en.wikipedia.org/wiki/Country_code_top-level_domain) 格式。例如，设置 `region=cn` 可优先返回中国大陆的结果。
</ParamField>

### 请求示例

```bash
# 正向地理编码：将"Beijing, China"转换为经纬度坐标
curl -X GET "https://maps.googleapis.com/maps/api/geocode/json" \
  -G \
  --data-urlencode "address=Beijing, China" \
  --data-urlencode "language=zh-CN" \
  --data-urlencode "region=cn" \
  --data-urlencode "key=YOUR_API_KEY"
```

### 响应示例

```json
{
  "status": "OK",
  "results": [
    {
      "formatted_address": "中国北京市",
      "geometry": {
        "location": {
          "lat": 39.9041999,
          "lng": 116.4073963
        },
        "location_type": "APPROXIMATE",
        "viewport": {
          "northeast": { "lat": 40.2164809, "lng": 116.8312329 },
          "southwest": { "lat": 39.4432579, "lng": 115.8418557 }
        }
      },
      "place_id": "ChIJuSwU55ZS8DURiqkPryBWgHQ",
      "address_components": [
        {
          "long_name": "北京市",
          "short_name": "北京市",
          "types": ["locality", "political"]
        },
        {
          "long_name": "中国",
          "short_name": "CN",
          "types": ["country", "political"]
        }
      ]
    }
  ]
}
```

<Note>
  `geometry.location` 中的 `lat` 和 `lng` 即为该地址对应的经纬度坐标，可直接用于 Maps JavaScript API 的 `center` 参数。
</Note>

## Directions API

Directions API 用于计算两地之间的路线，支持驾车、步行、骑行和公共交通四种出行方式，并可返回详细的导航步骤。

**Base URL：** `https://maps.googleapis.com/maps/api/directions/json`

### 请求参数

<ParamField query="origin" type="string" required>
  出发地。可以是地址字符串（如 `上海市`）、经纬度坐标（如 `31.2304,121.4737`）或 Place ID（如 `place_id:ChIJMzz1sUBwsjURoWTDI5QSlQI`）。
</ParamField>

<ParamField query="destination" type="string" required>
  目的地。格式与 `origin` 相同，支持地址、经纬度或 Place ID。
</ParamField>

<ParamField query="key" type="string" required>
  您的 Google API 密钥，需已启用 Directions API。
</ParamField>

<ParamField query="mode" type="string" default="driving">
  出行方式。可选值：
  - `driving`：驾车（默认）
  - `walking`：步行
  - `bicycling`：骑行
  - `transit`：公共交通
</ParamField>

<ParamField query="language" type="string">
  导航步骤说明的语言代码，例如 `zh-CN` 返回中文导航步骤。
</ParamField>

### 请求示例

```bash
# 查询从上海到北京的驾车路线，返回中文导航步骤
curl -X GET "https://maps.googleapis.com/maps/api/directions/json" \
  -G \
  --data-urlencode "origin=上海市" \
  --data-urlencode "destination=北京市" \
  --data-urlencode "mode=driving" \
  --data-urlencode "language=zh-CN" \
  --data-urlencode "key=YOUR_API_KEY"
```

响应中的 `routes[0].legs[0].duration.text` 和 `distance.text` 分别包含预计行程时间和总距离，`steps` 数组包含逐步导航指引。

## 计费说明

Google Maps Platform 采用**按量计费**模式，每月提供 **$200 免费额度**（约可支持数千次至数万次 API 调用，视 API 类型而定）。

| API | 定价（每 1000 次请求） |
|-----|----------------------|
| Maps JavaScript API（地图加载） | $7.00 |
| Geocoding API | $5.00 |
| Directions API | $5.00（基础）/ $10.00（高级） |
| Places API（地点搜索） | $17.00 |

<Note>
  每月 $200 的免费额度在账单周期结束时不会累计到下月。对于大多数个人和小型项目，免费额度已经足够日常使用。
</Note>

超出免费额度后，系统将按照上表价格自动计费。您可以在 Cloud Console 中设置**预算提醒**和**每日配额上限**，以避免意外超支。

<Warning>
  **生产环境必须限制 API 密钥权限！** 在 Google Cloud Console 的"凭据"页面中：
  - **Web 应用**：设置"HTTP 引用来源限制"，仅允许您的域名调用该密钥。
  - **服务器/后端**：设置"IP 地址限制"，仅允许您的服务器 IP 访问。
  - **移动应用**：分别为 iOS 和 Android 应用设置包名/Bundle ID 限制。

  未限制的 API 密钥一旦泄露，可能导致他人滥用您的配额，产生大额账单。
</Warning>
