## 账户与登录

<AccordionGroup>
  <Accordion title="忘记密码怎么办？">
    如果您忘记了 Google 账户密码，请按以下步骤重置：

    1. 前往 [accounts.google.com](https://accounts.google.com)，输入您的邮箱地址，点击**下一步**
    2. 在密码输入页面点击**忘记密码？**
    3. Google 会提供多种身份验证方式，例如：
       - 向您的备用邮箱发送验证码
       - 向您绑定的手机号发送短信验证码
       - 使用上次成功登录的设备确认身份
    4. 完成验证后，设置一个新的强密码

    <Note>
      如果您已长时间未登录该账户，且没有备用邮箱或手机号，账户恢复流程可能需要回答安全问题或提供账户相关信息。建议平时保持备用联系方式的更新。
    </Note>
  </Accordion>

  <Accordion title="如何开启两步验证？">
    两步验证（2-Step Verification）为您的账户增加了额外的安全保障，即使密码泄露也能有效防止他人登录。

    **开启步骤：**

    1. 前往 [myaccount.google.com/security](https://myaccount.google.com/security)
    2. 在**您登录 Google 的方式**部分，点击**两步验证**
    3. 点击**开始**，并按提示完成设置
    4. 选择您偏好的验证方式：
       - **Google 提示**：在已登录的手机上弹出确认提示（推荐）
       - **身份验证器应用**：使用 Google Authenticator 或 Authy 生成动态验证码
       - **短信验证码**：接收短信验证码（安全性相对较低）
       - **硬件安全密钥**：使用 YubiKey 等物理设备（安全性最高）

    <Tip>
      建议同时设置多种备用验证方式，以防主要方式不可用时仍能正常登录。
    </Tip>
  </Accordion>

  <Accordion title="如何切换 Google 账户？">
    如果您在同一浏览器中使用了多个 Google 账户，可以轻松切换：

    **在浏览器中切换：**

    1. 点击页面右上角的账户头像（通常显示您的姓名首字母或头像图片）
    2. 在下拉菜单中，您将看到当前已登录的所有账户
    3. 点击您想切换到的账户即可

    **添加新账户：**

    1. 同样点击右上角头像
    2. 选择**添加账户**
    3. 输入另一个 Google 账户的邮箱和密码登录

    **在移动应用中切换：**

    大多数 Google 应用（Gmail、Drive、Maps 等）支持多账户登录，点击应用内的账户头像即可切换。
  </Accordion>

  <Accordion title="账户被锁定如何解封？">
    Google 账户可能因多次输入错误密码、异常登录行为或违反服务条款而被暂时锁定。

    **常见解封方法：**

    **情况一：因多次密码输入错误被锁定**
    - 等待 **24 小时**后，账户锁定通常会自动解除
    - 或前往 [accounts.google.com/signin/recovery](https://accounts.google.com/signin/recovery) 进行账户恢复

    **情况二：因异常活动被暂停**
    1. 访问 [accounts.google.com/signin/recovery](https://accounts.google.com/signin/recovery)
    2. 按照页面指引完成身份验证
    3. 如需帮助，可通过 [support.google.com](https://support.google.com) 联系 Google 支持团队

    **情况三：因违反服务条款被停用**
    - 您会收到 Google 发送的说明邮件
    - 如您认为处理有误，可通过 Google 账户帮助中心提交申诉

    <Warning>
      如怀疑账户遭到他人入侵，请立即前往 [myaccount.google.com/security-checkup](https://myaccount.google.com/security-checkup) 进行安全检查，并更改密码。
    </Warning>
  </Accordion>
</AccordionGroup>

## API 与开发者

<AccordionGroup>
  <Accordion title="API 密钥和 OAuth 2.0 有什么区别？">
    这两种认证方式适用于不同场景，理解区别有助于您做出正确选择：

    | 对比维度 | API 密钥 | OAuth 2.0 |
    |----------|----------|-----------|
    | **适用场景** | 访问公开数据的服务端调用 | 需要访问用户私有数据的应用 |
    | **认证方式** | 在请求 URL 或 Header 中传递密钥字符串 | 用户授权后获取访问令牌（Access Token） |
    | **安全级别** | 较低（密钥泄露即全部权限丢失） | 较高（令牌有过期时间，权限可精细控制） |
    | **典型用途** | Maps API、YouTube Data API（只读） | Gmail API、Drive API、Calendar API |
    | **用户交互** | 不需要 | 需要用户登录并授权 |

    **简单原则：**
    - 如果您只需要访问**公开信息**（如地图、公开视频），使用 **API 密钥**
    - 如果您需要**代表用户**访问其私有数据，使用 **OAuth 2.0**
    - 如果是**服务器之间**的调用，使用**服务账号**
  </Accordion>

  <Accordion title="为什么我的 API 请求返回 403 错误？">
    HTTP 403 错误表示请求被服务器拒绝，但原因可能有多种：

    **常见原因及排查步骤：**

    1. **API 未启用**
       - 前往 Cloud Console 的 **API 和服务 > 已启用的 API 和服务**
       - 确认您调用的 API 已在当前项目中启用
       - 如未启用，前往 **API 库**搜索并启用该 API

    2. **账号权限不足**
       - 前往 **IAM 与管理 > IAM**，确认您的账号具有所需角色
       - 不同 API 所需的最低权限不同，请参阅对应 API 的文档

    3. **API 密钥受限**
       - 如果您使用了 API 密钥，检查该密钥是否设置了 HTTP 来源限制或 API 限制
       - 前往 **API 和服务 > 凭据**，点击密钥查看其限制配置

    4. **超出免费配额**
       - 部分 API 在超出免费用量后，若未关联有效结算账户，会返回 403 错误
       - 检查项目是否已关联有效的结算账户

    5. **服务账号权限不足**
       - 确认服务账号已被授予调用该 API 所需的角色
  </Accordion>

  <Accordion title="如何查看我的 API 配额使用情况？">
    您可以通过以下方式实时监控 API 的配额使用情况：

    **方法一：通过 Cloud Console 查看**
    1. 前往 [Cloud Console](https://console.cloud.google.com)
    2. 进入 **IAM 与管理 > 配额**
    3. 使用顶部筛选器选择具体的 API 服务
    4. 查看每项配额的当前使用量、上限及使用比例

    **方法二：通过 API 监控页面查看**
    1. 进入 **API 和服务 > 已启用的 API 和服务**
    2. 点击具体的 API 名称
    3. 在**配额**标签页中查看详细的配额使用图表

    **方法三：设置配额告警**
    - 在配额页面勾选关注的配额项，可设置阈值告警
    - 当使用量接近上限时，自动发送邮件通知

    <Tip>
      建议定期检查配额使用趋势，在使用量接近 80% 时提前申请扩容，避免业务中断。
    </Tip>
  </Accordion>

  <Accordion title="如何限制 API 密钥的使用范围？">
    为 API 密钥设置使用限制是防止密钥滥用的重要安全措施。

    **设置步骤：**

    1. 前往 **API 和服务 > 凭据**
    2. 点击您要限制的 API 密钥名称
    3. 在**密钥限制**部分，配置以下两类限制：

    **应用限制（限制请求来源）：**
    - **HTTP 来源网站**：仅允许指定域名的网页调用（适合前端 Web 应用）
    - **IP 地址**：仅允许特定 IP 或 IP 段发起请求（适合服务器端应用）
    - **Android 应用**：通过包名和签名证书指纹限制（适合 Android App）
    - **iOS 应用**：通过 Bundle ID 限制（适合 iOS App）

    **API 限制（限制可调用的 API）：**
    - 选择**限制密钥**，并仅勾选该密钥实际需要调用的 API
    - 避免使用"不限制"选项，以降低密钥泄露的风险

    4. 保存更改后，限制即刻生效

    <Warning>
      每当您的应用上线到生产环境前，请务必为 API 密钥配置适当的限制。切勿在公开代码或客户端代码中暴露未受限制的 API 密钥。
    </Warning>
  </Accordion>

  <Accordion title="服务账号和用户账号有何不同？">
    理解这两类账号的差异，有助于您在不同场景下选择正确的认证方式：

    | 对比维度 | 用户账号 | 服务账号 |
    |----------|----------|----------|
    | **代表对象** | 真实的人类用户 | 应用程序或自动化进程 |
    | **认证方式** | 用户名 + 密码 + 可选两步验证 | JSON 私钥文件或工作负载联合身份 |
    | **适用场景** | 交互式登录、开发调试 | 后端服务、定时任务、CI/CD 流水线 |
    | **权限管理** | 通过 IAM 角色分配 | 通过 IAM 角色分配，更细粒度 |
    | **数量限制** | 通常为个人使用 | 每个项目最多 100 个服务账号 |

    **最佳实践建议：**
    - 生产环境中的程序化访问，始终使用**服务账号**而非个人账号
    - 为每个应用或服务创建独立的服务账号，遵循最小权限原则
    - 定期轮换服务账号密钥，或使用工作负载联合身份避免管理密钥文件
  </Accordion>
</AccordionGroup>

## 计费与费用

<AccordionGroup>
  <Accordion title="免费套餐包含哪些内容？">
    Google Cloud 提供两种类型的免费优惠：

    **1. 新用户赠金（$300 免费赠金）**
    - 首次注册 Google Cloud 的新用户可获得价值 **$300** 的赠金
    - 有效期为自激活之日起 **90 天**
    - 可用于几乎所有 Google Cloud 产品和服务
    - 赠金用完或到期后，需要手动升级为付费账户，不会自动扣费

    **2. 始终免费层级（Always Free）**
    即使在赠金耗尽后，以下产品仍提供每月固定的免费用量：

    | 产品 | 每月免费用量 |
    |------|-------------|
    | Cloud Functions | 200 万次调用 |
    | Cloud Storage | 5 GB 区域存储 |
    | BigQuery | 1 TB 查询处理量 |
    | Cloud Run | 200 万次请求 |
    | Compute Engine | 1 个 e2-micro 实例（美国区域）|
    | Firestore | 1 GB 存储，5 万次读取/天 |

    <Note>
      免费层级的具体条款可能会更新，建议在 [cloud.google.com/free](https://cloud.google.com/free) 查看最新版本。
    </Note>
  </Accordion>

  <Accordion title="如何设置费用上限避免超额？">
    Google Cloud 提供多种费用控制机制，帮助您避免意外产生高额账单：

    **方法一：设置预算告警（推荐）**
    1. 前往 Cloud Console **结算 > 预算和提醒**
    2. 点击**创建预算**
    3. 设置预算金额及告警阈值（如 50%、90%、100%）
    4. 配置通知邮件或 Pub/Sub 主题

    **方法二：为具体服务设置配额上限**
    - 通过降低 API 配额上限，可间接限制费用上限
    - 前往 **IAM 与管理 > 配额**，手动降低特定 API 的配额

    **方法三：使用程序化方式自动停止服务**
    - 将预算告警与 Cloud Functions 集成
    - 当费用超过阈值时，自动触发函数停止或缩减资源

    <Warning>
      Google Cloud **不支持**设置硬性费用上限（即自动停止计费）。预算告警仅发送通知，不会自动停止服务。请确保配置了适当的告警并及时响应。
    </Warning>
  </Accordion>

  <Accordion title="如何申请退款？">
    如果您认为账单中存在错误计费或未经授权的费用，可以申请退款：

    **申请步骤：**

    1. 前往 Cloud Console **结算 > 交易**，找到需要申请退款的费用记录
    2. 点击该笔费用，查看详细信息
    3. 前往 [cloud.google.com/support](https://cloud.google.com/support) 提交支持请求
    4. 选择问题类型为**结算与付款**
    5. 在申请中说明以下信息：
       - 账单金额及对应时间段
       - 认为需要退款的原因
       - 相关的项目 ID 和结算账户 ID

    **退款处理时间：**
    - 一般在提交申请后 **5–7 个工作日**内处理
    - 退款将原路返回至您的信用卡或银行账户

    <Note>
      Google Cloud 的退款政策仅适用于特定情况（如服务故障或计费错误）。因自身使用超出预期而产生的费用，通常不予退款。
    </Note>
  </Accordion>

  <Accordion title="如何导出账单报告？">
    您可以将账单数据导出用于财务对账、成本分析或内部审计：

    **方法一：下载 PDF/CSV 账单**
    1. 前往 Cloud Console **结算 > 账单文件**
    2. 选择账期，点击下载 PDF 账单或 CSV 明细报告

    **方法二：将账单数据导出到 BigQuery（推荐用于深度分析）**
    1. 前往 **结算 > 账单导出**
    2. 点击 **BigQuery 导出** 标签，点击**修改设置**
    3. 选择目标 BigQuery 数据集（如需新建，先在 BigQuery 中创建）
    4. 开启**标准用量费用**和/或**详细用量费用**导出
    5. 保存后，账单数据将每天自动同步至 BigQuery，可用 SQL 进行灵活查询分析

    **方法三：导出到 Cloud Storage**
    - 在**账单导出**中配置 CSV 导出至指定的 Cloud Storage 存储桶
    - 适合需要与其他系统集成的场景
  </Accordion>
</AccordionGroup>

## Google Workspace

<AccordionGroup>
  <Accordion title="如何将域名绑定到 Workspace？">
    将自定义域名（如 `yourcompany.com`）绑定到 Google Workspace，可以使用企业专属的邮箱地址（如 `name@yourcompany.com`）。

    **步骤：**

    1. 登录 [admin.google.com](https://admin.google.com)，进入 **账户 > 域**
    2. 点击**添加域**，输入您的域名
    3. 选择添加类型：
       - **主域**：作为主要的电子邮件域名
       - **别名域**：用于接收邮件，但用户使用主域发送
    4. Google 会提供一条 **TXT 记录**用于验证域名所有权
    5. 登录您的域名注册商（如阿里云、腾讯云、GoDaddy 等），在 DNS 管理后台添加该 TXT 记录
    6. 返回 Google 管理员控制台，点击**验证**
    7. 验证成功后，按照提示配置 **MX 记录**，将域名的邮件流量指向 Google 的邮件服务器

    <Note>
      DNS 记录的生效时间通常为 **24–48 小时**，请耐心等待。在此期间，原邮件服务不会中断。
    </Note>
  </Accordion>

  <Accordion title="如何从 Microsoft 365 迁移数据？">
    Google 提供了官方的迁移工具，帮助您将 Microsoft 365（原 Office 365）的数据迁移到 Google Workspace。

    **可迁移的数据类型：**
    - 邮件（Exchange / Outlook）→ Gmail
    - 联系人 → Google 通讯录
    - 日历 → Google 日历
    - 文件（OneDrive、SharePoint）→ Google Drive

    **推荐迁移方式：使用 Google Workspace 迁移工具**

    1. 在 [admin.google.com](https://admin.google.com) 中，进入 **数据 > 数据迁移**
    2. 选择迁移来源为 **Microsoft Office 365**
    3. 使用 Microsoft 365 管理员账号授权访问
    4. 选择要迁移的用户范围（全部用户或特定用户）
    5. 配置迁移选项（数据日期范围、数据类型等）
    6. 开始迁移并在控制台中监控进度

    <Tip>
      建议先进行小规模试迁移（如 5–10 个用户），验证数据完整性后再进行全量迁移。整体迁移计划可能需要数天到数周，取决于数据量的大小。
    </Tip>
  </Accordion>

  <Accordion title="管理员如何重置员工密码？">
    当员工忘记密码或账户需要紧急处理时，Google Workspace 管理员可以直接重置密码。

    **通过管理员控制台重置：**

    1. 登录 [admin.google.com](https://admin.google.com)，使用管理员账号
    2. 进入 **目录 > 用户**
    3. 找到需要重置密码的用户（可通过搜索框查找）
    4. 点击用户名称进入用户详情页
    5. 点击**重置密码**
    6. 选择以下操作之一：
       - **自动生成密码**：系统生成随机密码，您可复制并告知员工
       - **手动设置密码**：自定义新密码
    7. 勾选**要求用户在下次登录时更改密码**（推荐）
    8. 点击**重置**完成操作

    **通过 gcloud CLI 重置（适合批量操作）：**

    ```bash
    # 使用 Google Workspace Admin SDK 重置指定用户密码
    gcloud alpha identity users update \
      user@yourcompany.com \
      --password="TempPassword123!" \
      --change-password-next-login
    ```

    <Warning>
      请通过安全渠道（如企业即时通讯工具或电话）将临时密码告知员工，避免通过电子邮件明文传送密码。
    </Warning>
  </Accordion>
</AccordionGroup>
