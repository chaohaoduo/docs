本指南将带您完成使用 Google 产品前的全部初始准备工作，包括创建 Google 账户、建立 Cloud 项目、配置结算账户以及启用所需 API。无论您是个人开发者还是企业用户，完成以下步骤后即可开始调用 Google 的各类 API 与服务。

## 快速开始

<Steps>
  <Step title="注册或登录 Google 账户">
    访问 [accounts.google.com](https://accounts.google.com)，点击**创建账户**开始注册流程。注册时需要提供以下信息：

    - **姓名**：您的真实姓名或组织名称
    - **用户名**：您希望使用的 Gmail 地址
    - **密码**：至少 8 位，建议包含字母、数字与特殊字符
    - **手机号码**：用于账户验证与安全保护（推荐填写）
    - **备用邮箱**：用于账户恢复（可选）

    <Note>
      如果您已拥有 Google 账户，可直接登录并跳过此步骤，前往第二步创建 Cloud 项目。
    </Note>
  </Step>

  <Step title="创建 Google Cloud 项目">
    项目是 Google Cloud 中所有资源的基本组织单元。请按以下步骤创建您的第一个项目：

    1. 前往 [console.cloud.google.com](https://console.cloud.google.com)
    2. 在页面顶部的项目选择器中，点击**新建项目**
    3. 填写项目信息：
       - **项目名称**：为项目起一个便于识别的名称，例如 `my-app-production`
       - **组织**：如果您属于某个 Google Workspace 组织，可在此选择；个人账户可留空
       - **项目 ID**：系统自动生成，也可手动修改（创建后无法更改）
       - **结算账户**：可在此关联，也可稍后设置
    4. 点击**创建**，等待项目初始化完成

    <Note>
      每个 Google 账户最多可创建 **25 个**项目。如需更多，请申请提高配额。
    </Note>
  </Step>

  <Step title="启用结算账户">
    部分 Google Cloud 服务需要关联有效的结算账户才能使用。首次注册的新用户可享受 **$300 免费赠金**，有效期 90 天。

    **绑定信用卡并开通结算账户：**

    1. 前往 [cloud.google.com/billing](https://cloud.google.com/billing)
    2. 点击**创建结算账户**
    3. 选择您所在的国家/地区
    4. 输入信用卡或借记卡信息（仅用于验证身份，免费赠金用尽前不会扣费）
    5. 确认服务条款并提交

    **将结算账户关联到项目：**

    1. 在 Cloud Console 中，进入**结算 > 项目管理**
    2. 找到您的项目，点击**更改结算账户**
    3. 选择刚创建的结算账户并确认

    <Warning>
      请妥善保管您的结算信息。建议设置预算告警，防止意外产生高额费用。详见[最佳实践](/guides/best-practices)中的费用管理章节。
    </Warning>
  </Step>

  <Step title="设置 IAM 权限">
    Identity and Access Management（IAM）允许您精细控制团队成员对项目资源的访问权限。

    **邀请团队成员：**

    1. 在 Cloud Console 中，进入 **IAM 与管理 > IAM**
    2. 点击顶部的**授予访问权限**
    3. 在**新主账号**字段输入成员的 Google 账户邮箱
    4. 在**角色**下拉菜单中选择合适的角色
    5. 点击**保存**

    **常用角色说明：**

    | 角色 | 权限范围 | 适用场景 |
    |------|----------|----------|
    | **Owner（所有者）** | 完全控制权，包括管理权限 | 项目负责人 |
    | **Editor（编辑者）** | 可读写大多数资源，但不能管理权限 | 开发工程师 |
    | **Viewer（查看者）** | 仅可查看资源，无法修改 | 审计人员、只读用户 |

    <Tip>
      遵循**最小权限原则**：为每位成员仅分配其工作所需的最低权限级别。详细的安全配置建议请参阅[安全最佳实践](/features/security)。
    </Tip>
  </Step>

  <Step title="启用所需 API">
    Google Cloud 的大多数 API 在使用前需要手动启用。

    **通过 API 库启用 API：**

    1. 在 Cloud Console 中，进入 **API 和服务 > 库**
    2. 在搜索框中输入您需要的 API 名称，例如 `Maps JavaScript API`
    3. 点击对应的 API 卡片
    4. 点击**启用**按钮，等待激活完成
    5. 重复以上步骤，启用所有所需的 API

    **常用 API 参考：**

    - `Cloud Storage API` — 对象存储
    - `Compute Engine API` — 虚拟机
    - `BigQuery API` — 数据分析
    - `Maps JavaScript API` — 地图服务
    - `Gmail API` — 邮件服务

    <Note>
      部分 API 启用后需要等待数分钟才能生效。如果请求仍然失败，请稍后重试。
    </Note>
  </Step>

  <Step title="生成 API 密钥或服务账号凭据">
    根据您的应用场景，选择合适的认证方式：

    **API 密钥（适合简单场景）：**

    - 适用于访问公开数据的 API，如 Maps、YouTube Data API
    - 操作简单，只需在请求中附加 `?key=YOUR_API_KEY`
    - 前往 **API 和服务 > 凭据 > 创建凭据 > API 密钥**
    - ⚠️ 建议为密钥设置**应用限制**（如 HTTP 来源域名）和 **API 限制**（仅限特定 API）

    **服务账号（适合服务器到服务器场景）：**

    - 适用于后端应用、CI/CD 流水线、自动化脚本等
    - 使用 JSON 格式的私钥文件进行认证，安全性更高
    - 前往 **IAM 与管理 > 服务账号 > 创建服务账号**
    - 创建完成后，下载 JSON 密钥文件并妥善保存

    <Warning>
      请勿将 API 密钥或服务账号私钥提交到公开的代码仓库中。建议使用环境变量或 Secret Manager 管理凭据。
    </Warning>
  </Step>
</Steps>

## 账户类型对比

根据您的使用场景，Google 提供了三种主要账户类型：

| 账户类型 | 使用场景 | 认证方式 | 适用产品 |
|----------|----------|----------|----------|
| **个人账户** | 个人开发、学习、个人项目 | 用户名 + 密码，支持两步验证 | 全部 Google 产品与服务 |
| **Google Workspace 账户** | 企业团队协作、组织级管理 | 与组织 SSO 集成，支持 SAML/OIDC | Gmail、Drive、Meet、Docs 等 Workspace 套件，以及 Google Cloud |
| **服务账号** | 应用程序间的自动化调用、后端服务 | JSON 私钥文件或工作负载联合身份 | Google Cloud API、Google Workspace Admin API |

<Tip>
  建议在生产环境中始终使用**服务账号**进行程序化访问，避免使用个人凭据。了解更多安全最佳实践，请访问[安全配置指南](/features/security)。
</Tip>

<Note>
  **关于免费套餐限制：** Google Cloud 提供"始终免费"层级，包含部分产品每月固定的免费用量（如 Cloud Functions 每月 200 万次调用、Cloud Storage 每月 5 GB 存储等）。当您超出免费用量后，系统将按实际用量计费。建议在 Cloud Console 的**结算 > 预算和提醒**中设置告警，及时了解费用情况。
</Note>
