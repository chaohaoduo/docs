  <Card title="计算服务" icon="server" href="https://cloud.google.com/products/compute">

    **Cloud Run**：无服务器容器运行平台，按实际请求计费，自动扩缩容至零，让您专注业务逻辑而非基础设施。

    **BigQuery**：全托管无服务器数据仓库，支持对 PB 级数据进行秒级 SQL 查询，内置 ML 能力与 BI 引擎。  
    **Cloud SQL**：全托管关系型数据库服务，支持 MySQL、PostgreSQL 与 SQL Server，自动备份与故障转移。
  </Card>
  <Card title="AI 与机器学习" icon="brain" href="https://cloud.google.com/products/ai">

    **Cloud Vision API**：强大的图像分析服务，支持物体检测、OCR 文字识别、人脸检测与内容审核。  
    **Natural Language API**：自然语言处理服务，提供情感分析、实体识别、语法分析与内容分类能力。
  </Card>

    **Cloud Load Balancing**：全球负载均衡服务，支持 HTTP(S)、TCP、UDP 流量分发，自动应对流量峰值。  
    **Virtual Private Cloud (VPC)**：软件定义的私有云网络，支持全球单一 VPC 架构与灵活的子网、路由与防火墙配置。
  </Card>
  <Card title="安全" icon="shield-halved" href="https://cloud.google.com/products/security">
    **Cloud IAM**：精细化身份与访问管理，基于最小权限原则控制谁可以对哪些资源执行哪些操作。  
    **Cloud Armor**：DDoS 防护与 Web 应用防火墙（WAF）服务，保护您的应用免受大规模网络攻击与 OWASP Top 10 漏洞威胁。  
    **Secret Manager**：安全存储和管理 API 密钥、密码、证书等敏感配置信息，支持版本管理与自动轮换。

## 快速部署示例

以下示例演示如何使用 `gcloud` CLI 将一个容器镜像快速部署到 Cloud Run，整个过程仅需数分钟：

```bash
# 第一步：配置默认项目与地区（将 YOUR_PROJECT_ID 替换为您的项目 ID）
gcloud config set project YOUR_PROJECT_ID
gcloud config set run/region asia-east1  # 使用台湾地区节点，亦可选择 asia-northeast1（东京）

# 第二步：构建容器镜像并推送至 Artifact Registry
gcloud builds submit --tag asia-east1-docker.pkg.dev/YOUR_PROJECT_ID/my-repo/my-app:v1

# 第三步：将容器镜像部署到 Cloud Run
gcloud run deploy my-app \
  --image asia-east1-docker.pkg.dev/YOUR_PROJECT_ID/my-repo/my-app:v1 \
  --platform managed \
  --allow-unauthenticated \
  --memory 512Mi \
  --concurrency 80

# 部署成功后，命令行将输出服务的公网访问 URL
# 示例：https://my-app-xxxxxxxxxx-de.a.run.app
```

<Note>
首次使用前，请确保已在项目中启用 Cloud Run API 与 Cloud Build API。您可以在 [Cloud Console](https://console.cloud.google.com) 的 **API 和服务** 页面中一键启用所需 API。
</Note>
