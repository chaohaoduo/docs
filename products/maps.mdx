Google Maps Platform 是 Google 面向开发者与企业提供的一套地图与位置服务 API，覆盖全球 **220 余个国家和地区**，拥有超过 2500 万条每日更新的地图数据。无论您是要在网页或移动端嵌入交互式地图、为用户提供实时路线规划，还是构建基于位置的个性化体验，Google Maps Platform 都能为您提供稳定、精准、可扩展的基础设施支撑。

---

## 核心产品

<CardGroup cols={2}>
  <Card title="Maps（地图展示）" icon="map">

  <Card title="Routes（路线规划）" icon="route">

  </Card>
</CardGroup>

## 使用场景

**外卖配送**
集成 Routes API 与 Maps JavaScript API，实现骑手实时位置追踪、最优配送路线规划与预计到达时间展示，显著提升配送效率与用户体验。

**打车应用**
利用 Maps SDK、Distance Matrix API 与 Geocoding API，快速匹配司乘双方位置，动态规划行驶路线，并在地图上实时展示车辆轨迹。

**旅游应用**
通过 Places API 获取景点详情、用户评分与营业时间，结合 Maps 嵌入地图为游客提供个性化行程规划与周边推荐服务。

**房产平台**
借助 Maps Embed API 与 Places API，在房源页面展示地周边配套（学校、医院、地铁站），帮助购房者更全面地评估地段价值。

## 快速集成 Maps JavaScript API

以下示例展示如何通过 Maps JavaScript API 在网页中加载一张以北京为中心的交互式地图：

```html
<!DOCTYPE html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>Google Maps 示例</title>
    <style>
      /* 地图容器需设置明确的宽高 */
      #map {
        height: 500px;
        width: 100%;
      }
    </style>
  </head>
  <body>
    <!-- 地图渲染容器 -->
    <div id="map"></div>

    <script>
      // 地图初始化回调函数
      function initMap() {
        // 设置地图中心点坐标（北京天安门广场）
        const beijing = { lat: 39.9042, lng: 116.4074 };

        // 创建地图实例并绑定到 #map 容器
        const map = new google.maps.Map(document.getElementById("map"), {
          zoom: 12,         // 缩放级别（1–20）
          center: beijing,  // 地图中心坐标
        });

        // 在中心点添加标注
        new google.maps.Marker({
          position: beijing,
          map: map,
          title: "北京天安门广场",
        });
      }
    </script>

    <!-- 加载 Maps JavaScript API，替换 YOUR_API_KEY 为您的真实密钥 -->
    <script
      src="https://maps.googleapis.com/maps/api/js?key=YOUR_API_KEY&callback=initMap"
      async
      defer
    ></script>
  </body>
</html>
```

<Tip>
  还没有 API 密钥？请参阅 [快速入门指南](/getting-started/quickstart) 了解如何创建 Google Cloud 项目并启用 Maps API。
</Tip>

## 计费说明

Google Maps Platform 采用**按需付费**定价模式，您只需为实际调用量付费，无需签订长期合同。

- **每月免费额度**：每个账号每月享有价值 **$200 美元**的免费调用额度，覆盖大多数中小型应用的日常用量。
- **超额计费**：超出免费额度的调用将按各 API 的单价计费，不同产品（Maps、Routes、Places）费率有所不同。
- **用量提醒**：建议在 Google Cloud Console 中设置预算提醒，避免意外超支。

  详细价格表及各 API 单价请访问 [Google Maps Platform 定价页面](https://mapsplatform.google.com/pricing/)。
</Note>
