## 迁移指南

从 Microsoft 365 或其他办公套件迁移至 Google Workspace 无需停工停产。按照以下步骤，您可以平稳、安全地完成整个迁移过程：

<Steps>
  <Step title="规划迁移策略">
    评估您现有的邮件账户数量、数据存储总量与关键业务流程。确定迁移优先级与时间表，建议先以小团队进行试点，再逐步推广至全组织。
  </Step>
  <Step title="设置 Google Workspace 账户">
    在 [Google Workspace 管理控制台](https://admin.google.com) 中创建组织账户，完成域名验证（通过添加 DNS TXT 记录），并按部门批量创建用户账户。
  </Step>
  <Step title="迁移电子邮件与日历数据">
    使用 Google 官方提供的 **数据迁移服务（Data Migration Service）** 或 **GAMME（Google Workspace Migration for Microsoft Exchange）** 工具，将历史邮件、联系人与日历事件从 Exchange / Outlook 迁移至 Gmail 和 Google 日历，全程数据加密传输。
  </Step>
  <Step title="迁移文件与文档">
    通过 **Google Drive for Desktop** 将本地或 SharePoint 中的文件批量上传至 Google 云端硬盘。Office 格式文件（.docx、.xlsx、.pptx）将自动转换为 Google 文档格式，原始文件同步保留。
  </Step>
  <Step title="培训与变更管理">
    利用 [Google Workspace 学习中心](https://support.google.com/a/users/answer/9282664) 为员工提供免费的在线培训资源。建立内部"Workspace 推广大使"团队，帮助同事解答使用问题，加速适应新工作方式。
  </Step>
  <Step title="停用旧系统">
    在确认所有数据迁移完整、业务流程运行正常后，逐步下线旧系统许可证。保留至少 30 天的过渡期以处理潜在的遗留问题。
  </Step>
</Steps>

<Tip>
Google Workspace 提供 **14 天免费试用**，无需信用卡即可体验全部功能。立即访问 [workspace.google.com](https://workspace.google.com/intl/zh-CN/) 开启您的免费试用，亲身感受智能协作的全新体验。
</Tip>

## 开发者 API 集成

Google Workspace 提供完整的 REST API，让您能够将 Gmail、云端硬盘与表格等服务深度集成到自己的应用和自动化工作流中。

<CardGroup cols={3}>
  <Card title="Gmail API" icon="envelope" href="https://developers.google.com/gmail/api">
    通过 **Gmail API** 以编程方式发送邮件、管理标签、搜索邮件线程，并构建基于电子邮件的自动化流程，例如工单系统或通知服务。
  </Card>
  <Card title="Google Drive API" icon="hard-drive" href="https://developers.google.com/drive/api">
    使用 **Google Drive API** 在云端硬盘中上传、下载、搜索和管理文件，设置共享权限，以及监听文件变更事件，实现文档管理自动化。
  </Card>
  <Card title="Google Sheets API" icon="table" href="https://developers.google.com/sheets/api">
    借助 **Google Sheets API** 读写表格数据、创建图表、应用格式，并将电子表格作为轻量级数据库或报表引擎集成到您的业务应用中。
  </Card>
</CardGroup>

以下示例展示如何使用 Google Sheets API 向指定表格追加一行数据：

```python
from googleapiclient.discovery import build
from google.oauth2 import service_account

# 使用服务账号凭据进行身份验证
credentials = service_account.Credentials.from_service_account_file(
    "YOUR_SERVICE_ACCOUNT_KEY.json",
    scopes=["https://www.googleapis.com/auth/spreadsheets"],
)

service = build("sheets", "v4", credentials=credentials)

SPREADSHEET_ID = "YOUR_SPREADSHEET_ID"   # 替换为您的表格 ID
RANGE = "Sheet1!A:C"                      # 目标写入范围

values = [["张三", "sales@example.com", "2024-01-15"]]
body = {"values": values}

result = (
    service.spreadsheets()
    .values()
    .append(
        spreadsheetId=SPREADSHEET_ID,
        range=RANGE,
        valueInputOption="USER_ENTERED",
        body=body,
    )
    .execute()
)

print(f"已追加 {result.get('updates', {}).get('updatedRows', 0)} 行数据")
```

<Note>
在调用任何 Workspace API 之前，请先在 [Google Cloud Console](https://console.cloud.google.com) 中为您的项目启用相应 API，并完成 OAuth 2.0 或服务账号凭据的配置。详细步骤请参阅 [API 身份验证指南](/api/authentication)。
</Note>
