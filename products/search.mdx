## AI 增强搜索

Google 搜索将 AI 能力深度融入每一个搜索环节，为您提供超越传统蓝色链接的智能体验。

**AI 概览（AI Overviews）**
基于 Google 的 Gemini 模型，AI 概览能够针对复杂问题自动综合多个来源的信息，在搜索结果顶部生成简洁、准确的摘要性解答，让您无需逐一点击网页即可获取核心信息。

**精选摘要（Featured Snippets）**
当您搜索特定问题时，Google 会从高质量网页中自动提取最直接的答案段落、表格或列表，置于搜索结果首位，显著提升信息获取效率。

**知识面板（Knowledge Panels）**
对于人物、地点、品牌、影视作品等实体信息，Google 会在搜索结果侧边栏展示结构化的知识卡片，整合来自 Google 知识图谱（Knowledge Graph）的权威数据，一目了然地呈现关键事实。

## 搜索技巧

掌握以下高级搜索语法，可大幅提升您的搜索精准度与效率：

<AccordionGroup>
  <Accordion title="精确搜索（引号 &quot;&quot;）">
    使用英文双引号将短语括起来，可强制 Google 搜索完全匹配该短语，避免搜索词被拆分。

    **示例：** `"人工智能安全"`  
    将只返回包含该完整短语的网页，而非分别包含"人工智能"和"安全"的页面。
  </Accordion>
  <Accordion title="排除关键词（减号 -）">
    在关键词前加上减号（`-`），可从搜索结果中排除包含该词的网页，帮助您过滤无关内容。

    **示例：** `苹果 -手机`  
    将返回有关苹果（水果）的信息，而非苹果（Apple）手机相关内容。
  </Accordion>
  <Accordion title="站内搜索（site:）">
    使用 `site:` 语法可将搜索范围限定在特定网站或域名内，快速检索目标站点的内容。

    **示例：** `site:developers.google.com Cloud Run`  
    将只在 Google 开发者文档网站内搜索 Cloud Run 相关内容。
  </Accordion>
  <Accordion title="文件类型搜索（filetype:）">
    使用 `filetype:` 语法可搜索特定格式的文件，支持 PDF、DOCX、XLSX、PPT 等常见格式。

    **示例：** `年度报告 filetype:pdf`  
    将直接返回 PDF 格式的年度报告文件。
  </Accordion>
  <Accordion title="时间范围过滤">
    在搜索工具栏中点击 **工具 → 时间**，或使用 `after:` / `before:` 语法过滤特定时间段内发布的内容，确保信息的时效性。

    **示例：** `大语言模型 after:2024-01-01`  
    将只返回 2024 年 1 月 1 日之后发布的相关内容。
  </Accordion>
</AccordionGroup>

## 开发者集成

如果您需要将搜索能力集成到自己的应用或工作流中，Google 提供了以下开发者工具：

<CardGroup cols={2}>
  <Card title="Custom Search API" icon="code" href="https://developers.google.com/custom-search/v1/overview">
    通过 **Programmable Search Engine** 在您自己的网站或应用中嵌入定制化搜索体验，支持限定搜索范围、自定义结果样式与过滤规则。
  </Card>
  <Card title="Maps JavaScript API" icon="map" href="https://developers.google.com/maps/documentation/javascript">
    将 Google Maps JavaScript API 集成到您的搜索应用中，为地点类搜索结果提供交互式地图展示，提升用户的位置信息体验。
  </Card>
  <Card title="Geocoding API" icon="location-dot" href="https://developers.google.com/maps/documentation/geocoding">
    使用 Geocoding API 将用户输入的地址或地点名称转换为精确的地理坐标（经纬度），为位置相关的搜索功能提供坚实的数据基础。
  </Card>
  <Card title="Knowledge Graph Search API" icon="diagram-project" href="https://developers.google.com/knowledge-graph">
    查询 Google 知识图谱，获取人物、地点、组织等实体的结构化数据，为您的应用提供丰富的语义信息支持。
  </Card>
</CardGroup>
